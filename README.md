# My Tasks

## 1. 앱 소개
**My Tasks**는 프레임워크나 외부 라이브러리 없이 브라우저에서 가볍고 빠르게 실행되는 할 일 관리(To-Do) 웹 애플리케이션입니다. 모든 데이터는 브라우저의 `localStorage`에 자동 보관되어 페이지를 새로고침하거나 브라우저를 다시 열어도 안전하게 유지되며, 모바일과 데스크톱 화면을 모두 지원하는 깔끔한 반응형 카드 UI를 제공합니다.

---

## 2. 주요 기능
- **할 일 등록 및 삭제**: 카테고리를 지정하여 간편하게 등록(Enter 키 및 버튼 클릭 지원)하고 개별 삭제할 수 있습니다.
- **완료 체크 및 인라인 수정**: 체크박스로 완료 상태(취소선)를 전환하며, 할 일 문구를 더블클릭하여 바로 수정(Enter: 저장, ESC: 취소)할 수 있습니다.
- **카테고리 분류 및 필터**: 업무(#4A90E2), 개인(#27AE60), 공부(#8E44AD) 색상 태그를 지원하며, 상단 필터 탭으로 모아볼 수 있습니다.
- **실시간 검색 및 상태 안내**: 검색어 입력 시 즉시 목록이 필터링되며, 표시할 항목이 없으면 친절한 안내 메시지를 표시합니다.
- **진행률 바 및 일괄 삭제**: 실시간 완료율(진행 건수 및 퍼센트)을 애니메이션 바로 시각화하며, 완료된 항목만 한 번에 정리할 수 있습니다.
- **반응형 2열 레이아웃**: 데스크톱(768px 이상)에서는 입력·진행률(좌측)과 목록·필터(우측)로 분리된 2열 뷰를 제공합니다.

---

## 3. 실행 방법
1. 프로젝트 폴더의 `index.html` 파일을 더블클릭하거나 웹 브라우저(Chrome, Edge 등)로 엽니다.
2. 별도의 설치나 서버 설정 없이 브라우저에서 즉시 사용할 수 있습니다.

---
